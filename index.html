鎖骨骨折

📝 考試重點

  • 好發部位：中1/3，兒童多見（青枝骨折）。
  • 移位機理：近端受胸鎖乳突肌牽拉向上後；遠端向前下內。
  • 特有體徵：頭向患側傾斜，下頜偏向健側。
  • 復位與固定：「叉腰挺胸，膝頂扳肩」。∞字繃帶固定。

肱骨外科頸骨折

⚖️ 核心考點：臨床分型對比

外展型

成角：向內

復位：由內→外

固定：內收位

內收型

成角：向外

復位：由外→內

固定：外展位

孟氏骨折

尺骨上1/3骨折 合併 橈骨頭脫位。💡 孟氏（猛撞）→ 傷在上面＋大頭。

蓋氏骨折

橈骨下1/3骨折 合併 下尺橈關節脫位。💡 蓋氏（蓋地）→ 傷在下面＋下尺橈。

肱骨幹骨折

中下1/3骨折易損傷橈神經（垂腕）。

肱骨髁上骨折

兒童最常見肘部骨折。肘三角關係不變（與脫位鑒別）。

橈尺骨幹雙骨折

最重要恢復前臂旋轉功能，防止交叉癒合。

肩關節周圍炎

📝 定義與別名

  • 以肩痛、肩關節活動障礙為主要特徵的筋傷。
  • 別名：漏肩風/露肩風（睡眠受涼）、凍結肩（活動如凍結）、五十肩（好發50歲）、肩凝風/肩凝症、粘連性關節囊炎。
  • 女性發病率高於男性，多為慢性發病。
  • 屬自限性疾病，病程數月至2年。

🔬 病因病機

  • 內因：年過五旬，肝腎漸衰、氣血虧虛、筋肉失於濡養 → 發病基礎。
  • 外因：肩部外傷勞損、外感風寒濕邪、因傷長期制動 → 誘發因素。
  • 病理：肩關節囊攣縮/關節外肌腱韌帶廣泛粘連，關節囊增厚，滑膜充血水腫，關節腔容量減小。
  • 西醫觀點：與自身免疫異常有關；與糖尿病、甲亢、冠心病、頸椎病高度相關。

🔍 診查要點

  • 多數慢性隱襲發病，多見中老年。
  • 疼痛以肩關節前、外側為重，夜間尤甚，影響睡眠。
  • 肩關節各方向運動受限，以外展、外旋、後伸障礙為著，重者出現「扛肩」現象。
  • 病程長者可見肩臂肌肉萎縮，尤以三角肌為明顯。
  • 壓痛部位：肩峰下滑囊、結節間溝、喙突、大結節等處。
  • 肩關節外展試驗陽性。
  • X線多無陽性發現（用於排除其他病）。

📋 臨床三期

🔴 1. 急性疼痛期（約1-3個月）

逐漸加重的肩部疼痛，因疼痛致肌肉痙攣、韌帶攣縮。肩關節尚有相當活動度。若積極治療，可直接進入緩解期。

🟡 2. 粘連僵硬期（約3-6個月）

疼痛逐漸減輕，但肩周軟組織廣泛粘連，活動範圍嚴重受限。出現「肩胛聯動症」「聳肩」現象及肌肉攣縮。

🟢 3. 緩解恢復期（約6個月）

疼痛基本消失，攣縮粘連逐漸消除，恢復正常功能。

⚖️ 鑒別診斷

鑒別要點肩周炎神經根型頸椎病肩袖損傷
臨床表現肩痛伴僵硬；主動被動均受限頸肩痛伴上肢放射痛麻木夜痛無力；被動多可
特殊檢查全面活動受限椎間孔擠壓、臂叢牽拉陽性Jobe試驗、落臂徵陽性
預後可自愈但慢常進行性加重重者需手術

💊 治療

  • 理筋手法：滾法/揉法/拿捏法→撥三角肌束→撥岡上肌/胸肌→牽拉抖動旋轉→幫助外展內收前屈後伸。隔日1次，10次1療程。
  • 藥物：風寒濕阻型→獨活寄生湯；瘀滯型→身痛逐瘀湯；氣血虧虛型→當歸鶏血藤湯。
  • 針灸：取肩髃、肩髎、臂臑、巨骨、曲池，「以痛為腧」。
  • 練功：「手指爬墻」「手拉滑車」「體後拉手」等，循序漸進，持之以恆。
🧗‍♂️
手指爬墻法：患者面對牆壁，用患側手指沿牆面向上爬行，逐漸提高高度，每日練習數次。這是肩周炎最經典的自我鍛煉方法。

特殊檢查：頸部

Cervical separation test

1. 分離試驗

🪑 體位：坐位
✋ 操作：一手托頦下，另一手托枕部，逐漸向上牽引頭部
✅ 陽性：頸部和上肢疼痛減輕
🏥 提示：神經根型頸椎病
🙆‍♂️⬆️
雙手托住頭部向上拉——像把頸椎「打開」，減少神經壓迫，所以疼痛減輕就是陽性。
Spurling's test

2. 椎間孔擠壓試驗

🪑 體位：坐位
✋ 操作：雙手手指相扣，掌面壓於頭頂，同時向左右或前後屈伸頸椎
✅ 陽性：頸部或上肢放射痛加重
🏥 提示：神經根型頸椎病 / 頸椎間盤突出症
🤲⬇️
向下壓頭＋側屈——像把椎間孔「擠窄」，壓迫神經根所以痛加重。與分離試驗方向相反！
Eaton's test

3. 臂叢神經牽拉試驗

🪑 體位：坐位，頭微屈
✋ 操作：一手推頭向對側，另一手握該側腕部相對牽引
✅ 陽性：患肢出現放射痛、麻木
🏥 提示：神經根型頸椎病
↔️🤕
頭推向一邊，手拉向另一邊——臂叢神經被拉緊，若有病變會出現放射痛。

特殊檢查：胸腰背部

1. 壓胸試驗

🪑 坐位/站立位 | 一手抵脊柱另一手壓胸骨相對擠壓
✅ 胸側壁某處疼痛 → 肋骨骨折
Lasègue's sign

2. 直腿抬高試驗 (SLR)

🛏️ 體位：仰臥，兩下肢伸直
✋ 一手握踝，一手扶膝保持伸直，逐漸抬高
✅ 小於70°即感傳導性疼痛/麻木 → 坐骨神經痛 / 腰椎間盤突出
🦵⬆️
正常可抬70-90°。注意配合加強試驗(Bragard)：抬至最大角度未引起痛時突然背屈踝關節，出現放射劇痛→腰椎間盤突出。
Ely test

3. 股神經牽拉試驗

🛏️ 俯臥位，膝完全屈曲足跟觸臀，後伸髖
✅ 大腿前方疼痛 → 上腰部椎間盤突出

特殊檢查：骨盆

1. 骨盆擠壓分離試驗

仰臥/側臥 | 雙手擠壓或分離髂骨翼
✅ 患處疼痛 → 骨盆骨折 / 骶髂關節病變

2. 屈膝屈髖試驗

仰臥 | 盡量屈曲髖膝，使臀部離床，腰部被動前屈
✅ 腰骶部疼痛 → 腰骶部病變（腰扭傷、勞損、骶髂關節病變）
Piriformis tension test

3. 梨狀肌緊張試驗

仰臥伸直患肢 | 內收內旋→若出現坐骨神經放射痛→迅速外展外旋
✅ 放射痛立刻緩解 → 梨狀肌綜合徵
Patrick's test / 4字試驗

4. 髖外展外旋試驗

仰臥 | 患側足架對側膝上呈「4」字，一手壓屈膝內側，另一手壓對側髂前上棘
✅ 骶髂關節處疼痛 → 骶髂關節病變
4️⃣
雙下肢擺成「4」字形，記住這個經典姿勢！主要檢查骶髂關節。

5. 斜扳試驗

側臥，下腿伸直，上腿屈髖屈膝90° | 一手推肩向背側，另一手推膝向腹側
✅ 骶髂關節疼痛 → 骶髂關節病變

特殊檢查：肩部

Dugas' sign

1. 搭肩試驗

坐/立位 | 肘屈曲，將手搭對側肩部
✅ 手能搭肩但肘不能貼胸壁；或肘貼胸壁但手不能搭肩 → 肩關節脫位
🤗❌
正常人可以搭肩同時肘貼胸壁。脫位後肱骨頭位置改變，兩者不能同時完成。

2. 肱二頭肌抗阻力試驗

屈肘90° | 患者用力屈肘外展外旋，檢查者抗阻力
✅ 結節間溝疼痛 → 肱二頭肌腱滑脫/長頭肌腱炎
Painful arc test

3. 疼痛弧試驗

坐/站 | 肩主動/被動外展
✅ 外展 60°~120° 範圍出現疼痛 → 肩袖病變
🙋‍♂️📐
60-120度這個特定區域叫「疼痛弧」。低於60°和超過120°反而不痛，因為肩峰下的撞擊只在這個角度範圍最明顯。
Supraspinatus tear test

4. 岡上肌腱斷裂試驗

坐/站 | 肩外展
✅ 外展30°~60°：三角肌收縮但不能上舉，越用力越聳肩。被動外展>60°後又能主動上舉 → 岡上肌腱斷裂/撕裂

特殊檢查：肘部

Cozen's Test

1. 腕伸肌緊張（抗阻力）試驗

屈腕屈指，檢查者壓手指背側對抗→再抗阻力伸指背伸腕
✅ 肱骨外上髁疼痛 → 肱骨外上髁炎 (Tennis Elbow)
Mill's sign

2. 腕伸肌腱牽拉試驗

一手置於外上髁，另一手使肘伸直、前臂旋前、腕屈曲
✅ 外上髁疼痛 → 肱骨外上髁炎 (網球肘)
Golfer's elbow test

3. 腕屈肌緊張試驗

患者握住檢查者手指，強力伸腕握拳對抗
✅ 肱骨內上髁疼痛 → 肱骨內上髁炎 (Golf Elbow)
Tinel Test

4. 叩診試驗

自遠端向病變區輕叩神經幹
✅ 遠端出現螞蟻走行/刺痛感 → 神經再生/神經瘤

5. 肘三角與肘直線

觀察肱骨內外上髁與尺骨鷹嘴
✅ 屈肘90°時三點成等腰三角形，伸直時在一條直線上。若改變 → 肘關節脫位/關節內骨折
🔺➡️➖
屈曲 = 三角形 △ ；伸直 = 直線 —。這是鑒別肘脫位（三角改變）與髁上骨折（三角不變）的重要方法！

特殊檢查：腕部

Finkelstein test

1. 握拳試驗（尺偏試驗）

拇指內收→屈曲其餘各指緊握拳→向尺側傾斜屈曲
✅ 橈骨莖突疼痛 → 橈骨莖突部狹窄性腱鞘炎

2. 舟骨叩擊試驗

手偏向橈側，叩擊第3掌骨頭
✅ 劇烈叩擊痛 → 手舟狀骨骨折
Phalen test

3. 屈腕試驗

屈肘前臂上舉，雙腕同時屈曲90°，持續1分鐘
✅ 橈側三個半手指疼痛/麻木 → 腕管綜合症（陽性率約70%）

特殊檢查：髖部

Yeoman's Test

髖關節過伸試驗

俯臥 | 屈膝90°，握踝提起下肢使髖過伸
✅ 骨盆隨之抬起 → 腰大肌膿腫 / 髖關節早期結核 / 關節強直

特殊檢查：膝部

McMurray's test

1. 迴旋擠壓試驗

仰臥 | 髖膝充分屈曲→檢查內側半月板：小腿內收外旋位伸直；外側：外展內旋位伸直
✅ 彈響+疼痛 → 半月板損傷
🔄🦵
記憶口訣：查內側半月板→小腿內收外旋；查外側→小腿外展內旋。方向相反！
Apley's test

2. 擠壓研磨試驗

俯臥，膝屈90° | 沿小腿軸向下壓+旋轉 → 半月板；向上提+旋轉 → 韌帶
✅ 壓+旋痛 → 半月板損傷；提+旋痛 → 側副韌帶損傷
Drawer test

3. 膝關節抽屜試驗

坐/仰臥，膝屈90°，檢查者坐於足背，雙手推拉小腿上段
✅ 前拉>1cm → 前交叉韌帶；後推>1cm → 後交叉韌帶
↔️🦴
像拉抽屜一樣前後推拉小腿！前抽屜→前交叉韌帶 (ACL)；後抽屜→後交叉韌帶 (PCL)。
Knee valgus stress test

4. 側方擠壓試驗

伸膝位 | 被動外翻或內翻
✅ 疼痛或角度超正常 → 側副韌帶損傷/斷裂

特殊檢查：踝部

Homans' test

1. 伸踝試驗

臥/坐 | 伸直小腿，用力背伸踝關節
✅ 小腿肌肉疼痛 / 深部觸診痛 → 小腿深靜脈血栓 (DVT)
🦶⬆️🔴
DVT是危險情況！背伸踝關節會牽拉腓腸肌，若有血栓會出現疼痛。臨床需高度警惕。

2. 蹠骨頭擠壓試驗

一手握足跟，另一手橫行擠壓5個蹠骨頭
✅ 前足放射樣疼痛 → 蹠痛病 / 扁平足 / 莫頓病

傷寒論：少陰病

🌟 少陰病 溫習重點整理

一、概說

  • 少陰 = 心（手少陰）＋ 腎（足少陰），為陰證危重階段。
  • 少陰與太陽相表裡：「實則太陽，虛則少陰」。
  • 心主血脈、主神明；腎為先天之本，內寓元陰元陽。
  • 病位在裡，多屬陰、虛、寒。
  • 預後取決於陽氣的存亡。
  • 治療禁忌：禁汗、禁下、禁火攻。

二、提綱證（281條）

「少陰之為病，脈微細，但欲寐也。」

  • 脈微 → 心腎陽衰，鼓動無力
  • 脈細 → 氣血虛少，脈道不充
  • 但欲寐 → 精神萎靡不振，似睡非睡（非嗜睡！）→ 陽衰精神失養

三、寒化 vs 熱化

寒化證熱化證
病機陽氣虛衰，陰寒內盛陰虛陽亢
心煩心煩但欲寐心煩不得臥
代表方四逆湯黃連阿膠湯
治法溫補陽氣（回陽救逆）育陰清熱

四、重要鑒別

  • 少陰 vs 太陰（虛寒下利）：少陰「欲吐不吐」「自利而渴」；太陰「腹滿而吐」「自利不渴」
  • 少陰寒利 vs 厥陰熱利：少陰「自利而渴小便白」；厥陰「自利而渴小便赤」
  • 格陽面赤 vs 陽明面赤：格陽「紅而嬌嫩、遊移不定、口和舌潤」；陽明「通紅不遊移、口渴舌乾」

少陰病提綱證的原文是「少陰之為病，脈微細，但欲寐也」。少陰屬心腎兩臟。試述少陰病提綱證的意義，包括「脈微」「脈細」「但欲寐」各反映的病機。

參考答案要點：
少陰屬心（手少陰）腎（足少陰）兩臟，心主血，屬火；腎藏精，主水。病則心腎陽虛衰，陰血不足。

脈微——心腎陽氣衰微，鼓脈無力，故脈微；
脈細——陰血不足，脈道不充，則脈細；
但欲寐——心虛則精神萎靡不振，腎虛則精不足，體力疲倦。患者呈似睡非睡、閉目倦卧的衰弱狀態（非高熱嗜睡！）。

「脈微細，但欲寐」是以全身性虛衰為病理特征的疾病，正因為此脈此證反映心腎陽虛俱衰，所以作為少陰病提綱證。

論述題 3（20分）

如何理解少陰病「急溫之」的脈證及意義？見于原文「少陰病，脈沉者，急溫之，宜四逆湯」。

參考答案要點：
原文僅言脈沉，尚未至脈微或脈微欲絕，說明雖陽虛並不太甚，但厥逆吐利諸典型裏虛寒證尚未出現，表示此時病情不重。

此處強調「急溫」，關鍵在于：病一入少陰，涉及根本，陽亡迅速，死證太多。所以少陰之治，貴在及早。

當脈沉顯示陽虛征兆時，即當急溫，以防亡陽之變。一旦延誤施治，則吐利厥逆諸證接踵而至，治亦晚矣。

本條文體現了中醫「治未病」的思想——見微知著，防患于未然。
