鎖骨骨折

📝 考試與溫習重點：

  • 好發部位：多發生在中1/3，兒童多見（常為青枝骨折）。
  • 移位機理：近端受胸鎖乳突肌牽拉向上後移位；遠端因肢體重量及胸大肌牽拉向前、下、內側移位。
  • 特有體徵：肩部向內、下、前傾斜，頭向患側傾斜，下頜偏向健側。
  • 復位與固定：復位手法為「叉腰挺胸，膝頂扳肩」。固定多用「∞字繃帶固定」。

肱骨外科頸骨折

⚖️ 核心考點：臨床分型對比

外展型骨折

成角：向內成角

復位：由內向外推

固定：肩關節保持內收位

內收型骨折

成角：向外成角

復位：由外向內推

固定：肩關節保持外展位

📝 其他重點：

  • 解剖弱點：位於解剖頸下2~3cm。內側有臂叢神經和腋動靜脈經過，極易合併神經血管損傷。

孟氏骨折

📝 定義與口訣

尺骨上1/3骨折 合併 橈骨頭脫位。

💡 記憶聯想：孟氏（猛撞） -> 傷在上面（尺骨上1/3）＋ 傷及大頭（橈骨頭）。

蓋氏骨折

📝 定義與口訣

橈骨下1/3骨折 合併 下尺橈關節脫位。

💡 記憶聯想：蓋氏（蓋地） -> 傷在下面（橈骨下1/3）＋ 傷及下尺橈。

肱骨幹骨折

最重要：中下1/3骨折易損傷橈神經（垂腕）。

肱骨髁上骨折

兒童最常見的肘部骨折。肘三角關係不變（與脫位鑒別）。

橈尺骨幹雙骨折

最重要恢復前臂旋轉功能，防止交叉癒合。

傷寒論：少陰病

🧩 重點條文填充訓練

💡 打中文會自動等選完字先跳格。填錯會標紅並加入「錯題庫」！

1. 少陰病提綱：
「少陰之為病，脈 ，也。」（281）
引導：想想少陰病最核心的虛寒脈象特徵，以及病人精神極度疲倦、似睡非睡的狀態。
2. 陽虛陰盛證：
「少陰病，脈 者， 之，宜 。」（323）
引導：脈象在深層，代表邪已入裏。治療需要把握時機（兩個字），並用最基礎的回陽救逆代表方劑。
3. 陰盛格陽證：
「少陰病，下利清穀，裏寒外熱，手足厥逆，脈微欲絕，身反不惡寒，其人面色赤... 主之。」（317）
引導：出現了「格陽」面色赤症狀，病情更重，需要在原本的回陽基礎方之上，加強宣通上下陽氣的力度。

👶 小兒推拿概論

📝 核心要點

  • 適用年齡：一般適用於 6 歲以下小兒，尤其 3 歲以下效果最佳。
  • 操作特點：輕快柔和、平穩着實。小兒皮膚嬌嫩，操作時常用滑石粉或介質。
  • 穴位特點：小兒推拿有其特定穴位（如三關、六腑、天河水等），多分佈在手部。
  • 注意事項：皮膚破損、急性傳染病、嚴重心臟病等禁用。

👶 小兒特定穴

📝 常考穴位

  • 推三關：前臂橈側，腕橫紋至肘橫紋。性溫熱，能補氣行氣、溫陽散寒。
  • 退六腑：前臂尺側，肘橫紋至腕橫紋。性寒涼，能清熱涼血、解毒。
  • 天河水：前臂正中，腕橫紋至肘橫紋。性微涼，清熱而不傷陰。
  • 脾經：拇指末節螺紋面。補脾經——旋推拇指螺紋面。
  • 肺經：無名指末節螺紋面。補肺經——旋推無名指螺紋面。

👶 小兒發熱

📝 辨證治療

  • 外感發熱：開天門、推坎宮、揉太陽、清肺經、推天河水。
  • 陰虛發熱：補腎經、揉二馬、推湧泉、清天河水。

👶 小兒腹瀉

📝 常用手法

  • 寒濕瀉：補脾經、推三關、補大腸、揉臍、推上七節骨、揉龜尾。
  • 濕熱瀉：清脾經、清大腸、清小腸、退六腑、推下七節骨。
  • 脾虛瀉：補脾經、補大腸、推三關、摩腹、捏脊。

👶 小兒咳嗽

📝 辨證手法

  • 外感咳嗽：推坎宮、揉太陽、清肺經、推天河水、揉肺俞。
  • 痰濕咳嗽：補脾經、清肺經、揉掌小橫紋、推揉膻中、揉豐隆。

落枕

📝 核心要點

  • 定義：因睡眠姿勢不良或頸部感受風寒，致頸部一側肌肉痙攣疼痛，活動受限。
  • 推拿治療：一指禪推頸項部→滾法→拿肩井→按揉風池、天柱、大椎→頸椎旋扳法。
  • 注意：旋扳前必須先充分放鬆肌肉，動作要穩。

頸椎病

📝 分型

  • 頸型：頸項僵痛，活動受限。
  • 神經根型：頸痛伴上肢放射痛、麻木（最常見）。
  • 脊髓型：四肢無力、行走不穩（最嚴重，推拿慎用）。
  • 椎動脈型：頭暈、視物模糊，與頭部轉動有關。

腰椎間盤突出

📝 核心要點

  • 好發部位：L4-5、L5-S1。
  • 特殊檢查：直腿抬高試驗 (SLR) 陽性。
  • 推拿治法：滾法放鬆腰臀→點按腎俞、腰陽關、環跳、委中→斜扳法→拔伸牽引。

肩周炎

📝 核心要點

  • 別名：五十肩、凍結肩、漏肩風。好發50歲左右。
  • 特徵：肩關節各方向活動均受限（外展、外旋尤甚）。
  • 推拿治療：滾法肩部→拿肩井→按揉肩髃、肩貞、天宗→搖肩關節→上肢搖抖。

頭痛

📝 辨經治療

  • 前頭痛（陽明）：按揉印堂、攢竹、陽白、合谷。
  • 側頭痛（少陽）：按揉太陽、率谷、風池、外關。
  • 後頭痛（太陽）：按揉風池、天柱、崑崙、後溪。
  • 巔頂痛（厥陰）：按揉百會、四神聰、太衝。

✋ 擺動類手法

📝 核心手法

  • 一指禪推法：拇指端著力，前臂擺動帶動拇指關節屈伸。頻率 120-160次/分。功力深透，適用全身穴位。
  • 滾法：手背近小指側著力，前臂旋轉帶動腕關節屈伸。頻率 120-160次/分。接觸面積大，適用腰背四肢。
  • 揉法：指或掌著力，做環形柔和揉動。分指揉、掌揉、前臂揉。

✋ 摩擦類手法

📝 核心手法

  • 推法：直線推動。分指推、掌推。
  • 擦法：掌面或大魚際直線往返摩擦，使局部產生熱感。不可擦破皮膚。
  • 摩法：掌面在體表做環形摩動，不帶動皮下組織。常用於腹部（順時針瀉，逆時針補）。
  • 搓法：雙掌夾住肢體做快速搓動，常用於上肢、脅肋。

✋ 振動類手法

📝 核心手法

  • 抖法：握住肢體遠端，做連續小幅度的上下抖動。常用於上肢放鬆。
  • 振法：指端或掌面著力，做高頻振動。能鎮靜安神、調和氣血。

✋ 擠壓類手法

📝 核心手法

  • 按法：拇指或掌根垂直向下按壓。常與揉法結合（按揉）。
  • 拿法：拇指與其餘四指對稱用力，捏拿肌肉。刺激較強。常用頸項、肩井。
  • 捏法：拇指與食中指捏起皮膚。捏脊法是小兒推拿重要手法。
  • 點法：指端或肘尖用力按壓穴位。刺激強烈，有類似針刺效果。

✋ 叩擊類手法

📝 核心手法

  • 拍法：虛掌拍擊體表。力量輕柔有彈性。適用肩背、腰臀、下肢。
  • 擊法：拳背、掌根或掌側擊打。力量較拍法重。

✋ 關節運動類手法

📝 核心手法

  • 搖法：使關節做被動環轉運動。常用頸、肩、腰、腕。幅度由小到大。
  • 扳法：固定一端，另一端做被動旋轉扳動。常用頸椎扳法、腰椎斜扳法。動作要穩準快。
  • 拔伸法：對關節或肢體做牽拉。用於頸椎牽引、骨折整復。力量持續均勻。

📊 EBP 概論

📝 核心概念

  • 定義：Evidence-Based Practice = 最佳研究證據 + 臨床專業經驗 + 患者價值觀與期望。
  • 五個步驟：Ask → Acquire → Appraise → Apply → Assess (5A)。
  • 意義：確保臨床決策有科學根據，提高診療質量和效果。

🔍 臨床提問 (PICO)

📝 PICO 框架

  • P (Patient/Population)：患者/人群特徵。
  • I (Intervention)：介入措施/治療方法。
  • C (Comparison)：對照措施。
  • O (Outcome)：預期結果/療效指標。
例：對於慢性腰痛患者(P)，推拿治療(I)與藥物治療(C)比較，能否更好地減輕疼痛(O)？

📚 文獻檢索

📝 常用數據庫

  • PubMed：最大醫學文獻庫，免費。
  • Cochrane Library：系統性回顧金標準。
  • CNKI/萬方：中文醫學文獻。
  • 檢索技巧：布爾邏輯 (AND, OR, NOT)、MeSH 詞。

🏆 證據等級

📝 證據金字塔（由高到低）

  • Level I：系統性回顧 / Meta-analysis of RCTs
  • Level II：隨機對照試驗 (RCT)
  • Level III：非隨機對照試驗 / 世代研究
  • Level IV：病例對照研究 / 病例系列
  • Level V：專家意見 / 個案報告

🧪 RCT 評讀

📝 評讀重點

  • 隨機化：是否正確隨機分配？分配隱藏 (Allocation concealment)？
  • 盲法：單盲/雙盲/三盲？對結果評估的影響。
  • 失訪率：Intention-to-treat (ITT) 分析 vs Per-protocol (PP) 分析。
  • 偏倚風險：選擇偏倚、實施偏倚、測量偏倚、報告偏倚。

📑 系統性回顧 / Meta-analysis

📝 核心概念

  • 系統性回顧 (SR)：系統地檢索、評估和綜合所有相關研究的方法。
  • Meta-analysis：用統計學方法合併多個研究的結果。
  • Forest plot：圖示各研究效果量，合併效果量。
  • 異質性：I² 統計量衡量研究間差異。I²>50% 提示高異質性。
  • Funnel plot：漏斗圖檢測發表偏倚。

📈 統計學概念

📝 常考指標

  • P 值：小於 0.05 通常認為具有統計學顯著性。
  • CI (信賴區間)：95% CI 不包含無效值（0或1）則有統計學意義。
  • RR (相對危險度)：暴露組與對照組事件發生率之比。
  • OR (比值比)：病例對照研究中的效果指標。
  • NNT (需治療人數)：需要治療多少人才能多產生1例好結果。NNT = 1/ARR。
  • 靈敏度 vs 特異度：靈敏度=真陽性率；特異度=真陰性率。

✅ 應用與評估

📝 核心要點

  • Apply：將證據結合臨床經驗和患者意願，應用於個別患者。
  • Assess：評估應用效果，是否改善了患者結局。
  • 障礙因素：時間不足、文獻獲取困難、統計知識不足、臨床環境限制。

🌡️ 生命體徵

📝 正常值

  • 體溫：口溫 36.3-37.2°C；腋溫 36.0-37.0°C；肛溫 36.5-37.7°C。
  • 脈搏：成人 60-100 次/分。
  • 呼吸：成人 16-20 次/分。
  • 血壓：正常 <120/80 mmHg；高血壓 ≥140/90 mmHg。

📋 健康評估

📝 核心要點

  • 問診：主訴、現病史、既往史、家族史、個人史。
  • 體格檢查：視診、觸診、叩診、聽診。
  • 護理評估工具：GCS 昏迷指數、Braden 壓瘡風險、Barthel 日常活動指數。

💊 給藥護理

📝 給藥安全

  • 三查七對：操作前、操作中、操作後核對。對床號、姓名、藥名、劑量、濃度、時間、用法。
  • 給藥途徑：口服、肌注、皮下注射、靜脈注射、外用。
  • 肌肉注射：十字法定位臀大肌注射點。進針角度 90°，深度 2.5-3cm。

💉 靜脈輸液

📝 核心要點

  • 滴速計算：每分鐘滴數 = 液體總量 × 點滴係數 / 輸液時間(分)。
  • 常見併發症：靜脈炎、液體外滲、空氣栓塞、循環負荷過重。
  • 空氣栓塞處理：左側臥位，頭低足高。

🩹 傷口護理

📝 傷口癒合分類

  • 一期癒合：傷口整齊，組織損傷少，無感染。直接縫合。
  • 二期癒合：傷口大，組織缺損多或有感染。肉芽組織填充。
  • 換藥原則：無菌操作，由內向外消毒（清潔傷口），由外向內消毒（感染傷口）。

🦠 感染控制

📝 核心要點

  • 無菌技術：無菌區、無菌物品、無菌操作原則。
  • 手衛生：WHO 五個時刻（接觸前、無菌操作前、體液暴露後、接觸後、環境接觸後）。
  • 隔離：接觸隔離、飛沫隔離、空氣隔離。
  • 消毒滅菌：高壓蒸汽滅菌（121°C, 15-30分鐘）最可靠。

🫁 氧療護理

📝 核心要點

  • 低流量吸氧：鼻導管 1-4 L/min。COPD 患者用低流量 1-2 L/min。
  • 吸氧濃度公式：吸氧濃度(%) = 21 + 4 × 氧流量(L/min)。
  • 注意事項：四防——防震、防火、防油、防熱。

🍎 營養護理

📝 核心要點

  • 鼻飼法：插管深度 45-55cm。灌食前先確認胃管在胃內。
  • 確認方法：①注射器抽吸胃液 ②聽診胃區氣過水聲 ③將胃管末端置入水中無氣泡。
  • 注意：每次灌食量 ≤200ml，間隔 ≥2 小時。溫度 38-40°C。

🚿 排泄護理

📝 核心要點

  • 導尿術：嚴格無菌操作。女性導尿管插入 4-6cm，男性 20-22cm。
  • 灌腸：大量不保留灌腸液量 500-1000ml，液溫 39-41°C，壓力：液面距肛門 40-60cm。
  • 留置導尿護理：每日清潔尿道口，保持引流通暢，定時夾管訓練膀胱功能。

🛡️ 安全與體位

📝 常見體位

  • 半坐臥位：心肺疾患呼吸困難、腹部手術後。
  • 端坐位：急性左心衰竭。
  • 側臥位：灌腸、昏迷患者防誤吸。
